# 🌱 Neural Bloom · 神经花开

> 从一个神经元出发，让知识逐层生长。

**Neural Bloom（神经花开）** 是一份面向零基础学习者的中文神经网络学习教案。项目采用“先理解直觉，再看公式，最后写代码”的路线，逐步从最简单的神经元走向多层神经网络与深度学习。

## 学习原则

- **先理解，再记公式**：每个数学表达式都配有直观解释和计算例子。
- **从小模型开始**：先手算一个神经元，再逐步增加层数和参数。
- **代码尽量从零实现**：在理解核心机制之前，不急着依赖大型深度学习框架。
- **持续迭代**：每完成一个阶段，就整理教案、校验代码，并更新学习进度。

## 第一章：从一个神经元到会学习的网络

本章汇总第 1～6 课，建立神经网络的基本概念，并使用 NumPy 从零训练一个能够学习 XOR（异或）关系的小网络。

| 课次 | 主题 | 学完应该理解什么 |
|---|---|---|
| 第 1 课 | 一个神经元 | 输入、权重、偏置与输出 |
| 第 2 课 | 多个神经元组成网络 | 输入层、隐藏层、输出层与激活函数 |
| 第 3 课 | 损失函数 | 如何衡量预测结果与正确答案的差距 |
| 第 4 课 | 梯度下降 | 如何根据梯度调整参数、降低损失 |
| 第 5 课 | 反向传播 | 如何用链式法则计算各个参数的梯度 |
| 第 6 课 | 第一个可训练网络 | 使用 NumPy 训练 XOR 神经网络 |

## 环境准备

第一章的 XOR 示例需要 Python 3.10 或更高版本及 NumPy：

```bash
python -m pip install numpy
python examples/01-xor_numpy.py
```

后续的 MNIST 实战将使用 PyTorch 与 torchvision，届时会在对应教案中说明安装与运行方式。
